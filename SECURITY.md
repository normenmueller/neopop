# Security Policy

## Supported Versions

Until 1.0.0, all released 0.x versions are supported with security fixes on a best-effort basis.

| Version | Supported |
| ------- | ----------|
| 0.x     | ✅        |
| <0.1    | ❌        |

## Reporting a Vulnerability

Please use the **“Report a vulnerability”** button on GitHub (private report).

**Please do not open public issues or pull requests for suspected vulnerabilities.**

## What to Expect (SLA)

- **Acknowledgement:** within 7 days.
- **Initial assessment:** within 14 days.
- **Fix & release:** best-effort; we will coordinate an embargo and publish details after a patched release.

## Scope

- Code in this repository and published releases.
- Excludes third‑party dependencies (we will upstream or track advisories as needed).

## Disclosure

We follow coordinated disclosure: we discuss privately, prepare a fix, then publish an advisory after release.
